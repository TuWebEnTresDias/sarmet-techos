# Sarmet Techos

Primera versión personalizada de la web para Sarmet, basada en la demo de techista compartida en el chat.

## Contenido

- Landing estática en HTML, CSS y JavaScript.
- Enfoque exclusivo en trabajos de techos en Catamarca Capital.
- Galería de modelos de referencia con consulta individual por WhatsApp.
- El modelo elegido se incluye en el texto del mensaje de WhatsApp.
- Diseño responsive, pensado primero para móvil.
